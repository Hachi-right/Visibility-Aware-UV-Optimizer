# 场景：用户明确指导

## 用户输入

“以后你汇报时先说结论和验证结果，不要先讲一大堆过程。”

## 处理

1. 确认当前 author。
2. 读取 `沟通偏好.md`，检查是否已有同类偏好。
3. 在 `沟通偏好.md` 的默认沟通方式中更新一条：
   - 场景：收尾汇报
   - 偏好：先说结论和验证结果，再补过程摘要。
   - 来源：用户明确要求，日期。
4. 在当前任务 `process.md` 记录本次学习。

## 不写入

- 不把这条偏好写到根目录 `沟通规范.md`；如果后续 leader 判断适合团队通用，再另走公共化流程。
- 不改其他 author 的 `沟通偏好.md`。
