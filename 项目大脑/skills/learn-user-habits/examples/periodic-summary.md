# 场景：周期性总结

## 输入

用户要求：“总结一下最近我一直纠正你的习惯，能沉淀的写下来。”

## 处理

1. 读取当前任务 `process.md`、`任务指标.md` 和已有私人软上下文。
2. 找到多次出现或用户明确强调过的行为要求。
3. 分类：
   - 验收节奏、阶段入库、停止条件写 `工作习惯.md`。
   - 协作姿态、公共/私人边界、长期记忆整理方式写 `协作灵魂.md`。
   - 报告结构、风险表达、会议整理规则写 `沟通规范.md`。
   - 回复长度、称呼、别名、个人细节偏好写 `沟通偏好.md`。
   - 身份、昵称、职责背景写 `用户画像.md`。
4. 每条都写来源；证据不足的只写当前任务 `process.md` 作为候选观察。

## 示例输出到 process.md

```markdown
## YYYY-MM-DD 学习用户习惯

- 已更新 `工作习惯.md`：阶段验收通过后入库；来源为多次用户明确要求。
- 已更新 `沟通规范.md`：收尾汇报先说结论和验证结果；来源为本轮用户明确指导。
- 未写入：一次性任务安排，原因是只对当前任务有效。
```
