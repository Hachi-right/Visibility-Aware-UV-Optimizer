# 启动与任务 Skill 索引

> 用途: 冷启动、workstate、用户区初始化、worktree 与任务目录生命周期。

| 文档 | 何时查看 |
| --- | --- |
| `skills/generate-workstate/` | 生成或刷新根目录 `workstate.json`，绑定当前 author 和当前任务目录。 |
| `skills/project-startup-check/` | 冷启动检查；校验分支、workstate、用户区、私有扩展目录和当前任务。 |
| `skills/init-project-info-user/` | 创建或补齐当前 author 的用户基础结构。 |
| `skills/create-project-worktree/` | 在 main/master 上创建任务 worktree，并锚定 author / Git identity / workstate。 |
| `skills/start-project-task/` | 创建新任务目录与任务工件，并更新当前任务指针。 |
| `skills/resume-project-task/` | 继续旧任务，把 `workstate.json.task_folder` 指回确认的旧任务目录。 |
| `skills/fork-project-task/` | 从旧任务派生新任务，复制源 task 并使用新目标继续。 |
