# 路径约束

## skill 内资源

从仓库根目录引用本 skill 脚本：

```text
项目大脑/skills/generate-workstate/scripts/generate_workstate.py
```

## 用户区

当前 author 的长期信息放在：

```text
项目大脑/用户/{author}/
```

任务目录放在：

```text
项目大脑/用户/{author}/tasks/{YYYY-MM-DD}-{task-slug}/
```

## 本机状态

唯一的本机状态文件在仓库根目录：

```text
workstate.json
```
