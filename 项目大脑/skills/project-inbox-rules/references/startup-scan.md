# 收件启动扫描

## 时机

按 `主流程.md` §1 必读链第 6 步：加载完当前 author `私有流程.md` 后执行。

## 扫描范围

- 目录：`项目大脑/用户/{author}/收件/`
- 文件：文件名日期为**当天**的 `*.md`

## 读取边界

- 只读各文件头（至 `---` 为止）
- **不读**分隔线以下正文

## 口述规则

| 状态 | 行为 |
| --- | --- |
| `待处理` | 向收件人口述摘要，并提示待办 |
| `已处理` | 不逐项口述；合并汇报「今日 X 件已处理、Y 件待处理」 |
| 当天无 `待处理` | 可跳过口述 |

## 展开正文

仅当用户说「展开收件」「读收件 {文件名}」或指定文件名时，才读 `---` 以下正文并按分工执行。

## 重载

启动完成、恢复会话或长会话重载后，按 `主流程.md` §5 重跑 §1 必读链（含本扫描）。
