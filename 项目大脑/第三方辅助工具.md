# 第三方辅助工具

本文记录项目大脑依赖的低频第三方辅助工具和 agent 运行增强。它们不是冷启动主流程的一部分；只有当前任务需要代码图谱、可视化汇报、工具安装、MCP 适配或 hook 排查时才读取。

## 使用原则

- 先检测，已有就跳过；缺失时再安装或补配置。
- 安装和初始化优先交给子 agent 或单独线程处理，不阻塞主任务推进。
- 全局工具只安装一次；项目级索引或缓存只在当前仓库初始化。
- 不把第三方工具源码拷贝进本仓库，只记录安装方法、检测方法和本项目适配经验。
- 不提交本机缓存、token、cookie、`.codegraph/`、浏览器态登录信息或个人 MCP 密钥。

## Agent 压缩与长会话 Hook

用途：会话启动/恢复、上下文压缩前后提醒或注入“先启动项目大脑、重新读取落盘任务上下文”的指令，防止跳过启动或只依赖压缩摘要继续工作而跑偏。

长会话提醒只用于低频防跑偏，不替代压缩后的上下文恢复。默认阈值是 30 轮，且脚本强制阈值不低于 20 轮；计数写入 Git 本地私有区 `.git/info/project-info-turn-reminder.json`，不写 `workstate.json`，避免每轮把仓库弄脏或制造合并冲突。

### 能力边界

| Agent | 当前结论 | 项目处理 |
| --- | --- | --- |
| Codex | `SessionStart` 是 thread scope，matcher 可覆盖 startup / resume / clear / compact；通过 `hookSpecificOutput.additionalContext` 给模型加入额外上下文。`PreCompact` / `PostCompact` 支持 `systemMessage`，但官方描述是 UI / event stream 警告。`Stop` 可用 `decision: block` 续一轮，但项目已有启动和压缩恢复通道，默认不加长会话 Stop。 | 已配置 `.codex/hooks.json`：`SessionStart` 覆盖 startup / resume / clear / compact，负责注入启动或重载提醒；`PreCompact` / `PostCompact` 只做提醒。 |
| Cursor | 官方 `preCompact` 是 observational hook，不能 block 或修改 compaction；输出只有 `user_message`。本机 Cursor hook skill 有 `stop` 事件，但输出能力清单未确认 `stop` 可向 agent 注入后续上下文。 | 已配置 `.cursor/hooks.json`：只在 `preCompact` 显示用户提醒；不配置伪注入的 turn hook。 |
| Claude Code | 官方有 `PreCompact` / `PostCompact`，但 compact 时点不适合作为上下文注入口。本机 Claude Code/KSCC `1.1.20` 实测拒绝 `Stop hookSpecificOutput.additionalContext`；`Stop` 支持 `decision: "block"` + `reason`，会把 reason 作为 synthetic user message `Stop hook feedback` 送入下一轮模型。 | 已配置 `.claude/settings.json`：`Stop` 每 30 轮通过 `hooks/project_info_turn_reminder.py` 输出 `decision:block` + `reason`，低频提醒重读任务文件和必要时落盘。 |
| CodeWhale | 0.8.x 本机公开 CLI / feature / config 未显示 compact hook；源码枚举只有 `session_start`、`session_end`、`message_submit`、`tool_call_before`、`tool_call_after`、`mode_change`、`on_error`、`shell_env`，其中 `message_submit` 是 observer-only，不能修改发给引擎的消息。 | 不配置 compact 或 turn hook；仍按主规则要求压缩后或长时间运行后重读任务文件。 |

调研依据：

- Codex 官方 hooks 文档：`https://developers.openai.com/codex/hooks`
- Cursor 官方 hooks 文档：`https://cursor.com/docs/hooks`
- Claude Code 官方 hooks 文档：`https://docs.anthropic.com/en/docs/claude-code/hooks`
- CodeWhale 本机版本：`codewhale (npm wrapper) v0.8.47`，`codewhale-tui 0.8.66`

### 项目级文件

- `.codex/hooks.json`
- `.cursor/hooks.json`
- `.claude/settings.json`
- `hooks/project_info_compact_reminder.py`
- `hooks/project_info_turn_reminder.py`

行为：

- 读取根目录 `workstate.json`，定位当前 `author` 和 `task_folder`。
- 提醒或注入：先读取当前任务 `process.md`、`design.md`、`任务范围.md`、`任务指标.md`。
- 不把这些文件正文直接注入上下文，避免重复污染和超长输出。

约束：

- 项目级 hook 需要 Codex 信任项目 `.codex/` 配置后才会运行。
- Cursor 项目级 hook 需要 Cursor 读取并信任 `.cursor/hooks.json` 后才会运行。
- Claude Code 项目级 hook 需要 Claude Code 读取并信任 `.claude/settings.json` 后才会运行。
- hook 只负责把提醒放到对应工具支持的通道；收到提醒后仍必须实际读取落盘文件。
- 未确认支持 compact 时点模型上下文注入的工具，不配置“伪注入”。
- turn 计数提醒不复制 `process.md` / `design.md` 正文，只提供路径和动作提示；达到阈值后重置计数。

## CodeGraph

用途：为代码库建立符号图谱，提升跨文件查找、调用路径分析和影响面判断效率。代码搜索时机由 `project-code-map` 控制：先用私有/公共代码地图产出查询规划卡，再把规划卡里的文件、符号、协议或配置锚点交给 CodeGraph 验证调用链和影响面；不要把 CodeGraph 当作跳过代码地图的裸搜入口。

检测：

```powershell
codegraph version
codegraph status --json .
```

如果没有 `codegraph` 命令：

```powershell
npm install -g @colbymchenry/codegraph
```

如果命令存在但当前仓库没有索引：

```powershell
codegraph init .
```

项目索引生成在 `.codegraph/`，它是本机缓存，必须保持在 `.gitignore` 中。

新任务 worktree 通过 `项目大脑/skills/create-project-worktree/scripts/create_project_worktree.py` 创建时，会强制调用 `scripts/init_codegraph_for_worktree.bat`，由 bat 在新 worktree 根目录执行 `codegraph init .`。这一步属于 worktree 创建后置流程，不再依赖 agent 临场判断是否要初始化。

Agent 适配：

| 工具 | 建议方式 |
| --- | --- |
| Codex | `codegraph install --target codex --location global --yes`；或把 `codegraph serve --mcp` 配到 `~/.codex/config.toml`。 |
| Cursor | `codegraph install --target cursor --location global --yes`；或把 `codegraph serve --mcp --path ${workspaceFolder}` 配到 `~/.cursor/mcp.json`。 |
| CodeWhale | CodeGraph 官方 installer 当前没有 `codewhale` target；检测并维护 `~/.codewhale/mcp.json` 中的 `codegraph` MCP server。 |

## cc-artifact

用途：把较长 HTML 报告、流程图、设计说明页发布到本地浏览器 artifact viewer，方便人审阅。

检测：

- Codex：检查是否存在本机 skill `~/.codex/plugins/cache/personal/cc-artifact/*/skills/artifact/SKILL.md`。
- Cursor：检查 `~/.cursor/mcp.json` 是否有 `cc-artifact` server。
- CodeWhale：检查 `~/.codewhale/mcp.json` 是否有 `cc-artifact` server。

安装或补配置以本机插件说明为准。项目只保留检测和适配经验，不复制插件源码。

## 执行入口

需要检测 CodeGraph 或 cc-artifact 时，先读本文件对应章节；需要安装或初始化时，优先开子 agent 执行安装命令，主任务继续推进。安装完成后把结果写入当前任务 `process.md`。
