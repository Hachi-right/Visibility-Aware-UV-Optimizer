# VUV 0.5.6 方向一致性验收标准

## 必须通过

- 每个已解析硬表面 UV 岛的选定模型正轴映射到 UV `+V`，最终残差不超过 `3°`。
- `AUTO` 固定按 `+Z -> +X -> +Y`，所有合法岛必须解析；不得在回放时换轴。
- 手动轴可让法线平行盖面 unresolved，但已解析岛最终丢轴必须失败。
- 所有方向锁定 Pack 禁止旋转；修复、投影和 float32 回放后重新对齐或复审。
- Adaptive 与关闭分组路径都必须严格匹配完整 face-set 并绑定 Pack 前原选轴。
- 任一方向失效、face-set 变化或回放异常都恢复源 UV、Seam 和交互状态。
- Unique 输出必须在 0-1、坐标有限、正 winding、零退化、零正面积重叠，并保持
  UV discontinuity 与 Seam 一致。
- Blender 3.3.5 与 5.2.0 LTS 的方向几何、完整方向管线、分组布局、Unique 修复和
  strict smoke 五组测试全部通过。
- 拼接武器 `VUV_Directed_v24` 的 887 个岛全部可解析、零侧转、零倒置、零超容差；
  拓扑、Seam 与源 UV 图层不变。
- 发布 ZIP 唯一顶层为 `visibility_uv_optimizer/`，精确 15 个白名单文件，逐文件
  SHA-256 与源码一致，不含缓存；SHA 表 8/8 匹配。

## 人工检查

- 使用带字母、编号或箭头的方向棋盘格检查正反；纯双色方格不能证明 180 度一致。
- 对最重要的主体面、左右对称结构和重复机械件检查共同朝向与材质接缝位置。

## 已知限制

- `0.5.6` 仍是受控试验版；零面积、严重非流形或无法生成合法 Unique 图表的资产会
  被严格拒绝并回滚，而不是强行提交结果。
- v24 实测场景为 Blender 5.2 格式，Blender 3.3 兼容性由合成回归和发布包 smoke
  覆盖，不能直接打开该场景复核。
