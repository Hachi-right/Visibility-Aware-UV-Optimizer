# 团队公理

> **团队公理（Team Axioms）** 是从多条 `团队经验/` **抽象升维**后的深层原则——回答项目内共享的**「为什么」**。
>
> **贵在精而不在多。** 只写团队共识；达不到抽象深度就不落盘。

## 三层认知分轨

| 层 | 路径 | 回答 |
| --- | --- | --- |
| **团队经验** | `团队经验/entries/` | 在什么争论里、为何有效 |
| **团队公理** | `公理/entries/` | 跨情境深层原则 |
| **团队规则** | `docs/规则/` | 做某类事时必须遵守的不变量 |

**加载**：先读本 index → 点读 0–2 篇 `entries/`；情境回 `source_experiences` 列团队经验。**禁止**一次全量加载全部正文。
