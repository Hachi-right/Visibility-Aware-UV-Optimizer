# 经验认知索引

> **团队经验入口**（实习生模板 · 空库）
>
> **经验认知（Experience Cognition）** 是从 task 中提炼的非共识判断——反常点 + 反推机制，不是 SOP。
>
> 区别于 `docs/规则/`（团队硬规则）、`项目大脑/公理/`（团队深层原则）及成员私人 `skills/personal-axioms/`，经验认知是**项目情境下的判断滤镜**。

---

## 如何使用

### 快速浏览（本 INDEX）

**何时看索引**：

- 开始战略取舍、协作边界、项目大脑结构相关任务时
- 整理/沉淀私人经验，需要确认收录边界时
- 需要找到与当前争议相关的经验类别或条目时

### 深度阅读（单篇正文）

**何时看 `entries/*.md`**：

- 任务涉及具体争议，需要理解「为何有效」和「何时用到」
- 用户明确要求参考团队经验时

**加载规则**：先读本 INDEX，再按索引挑 1~3 篇相关正文精读；**禁止**一次全量加载 `entries/`。外部原文见 `references/INDEX.md`，触发溯源时才点读。
